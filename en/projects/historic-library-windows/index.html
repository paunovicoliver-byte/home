Heritage windows · Public building

Windows for a historic library

Surveying, repairing and reproducing the wooden windows of a public library, so the building could keep its original character.

Project type
Heritage windows · Public building
Materials
  • Solid timber matched to the originals
  • Traditional joinery
  • Finish agreed with the project team

The project

Library windows are made for light and for long days of reading. The originals in this building had served for generations — some were still sound, others had reached the end of their life.

We approached the façade window by window, deciding in each case whether to repair, to reproduce, or — only where unavoidable — to replace.

The challenge

Several windows had decayed bottom rails and loose joints, while their profiles and proportions were an essential part of the façade.

Our approach

We measured the existing windows and recorded their profiles before any work began.

Sound frames were repaired with new timber spliced in where needed; windows beyond repair were reproduced with the same divisions and profiles.
